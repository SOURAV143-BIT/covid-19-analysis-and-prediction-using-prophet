# 🦠 COVID-19 Data Analysis and Forecasting

## 📖 Overview

This project analyzes the global spread of COVID-19 using data analysis and visualization techniques. It explores trends in confirmed, active, recovered, and death cases across different countries and uses Facebook Prophet for forecasting future cases.

The goal of this project is to gain insights into the pandemic through Exploratory Data Analysis (EDA) and Time Series Forecasting.

---

## 🎯 Objectives

* Analyze global COVID-19 trends.
* Visualize confirmed, active, recovered, and death cases.
* Identify the most affected countries.
* Compare COVID-19 statistics among major countries.
* Forecast future COVID-19 cases using Prophet.
* Generate meaningful insights through data visualization.

---

The dataset contains daily COVID-19 statistics for multiple countries.
